# SILC 学习资源共享社区

非官方整理的上海大学悉尼工商学院学习资料汇总。

## 服务项目

- [Course Materials](https://github.com/shu-silc-osc/course-materials)：课程资料汇总

## 贡献指南

欢迎共享与课程学习相关的资料、课堂笔记和整理内容。你可以通过提交 Pull Request 的方式补充资料、修正错误或改进目录结构。

提交内容前，请确认资料适合公开分享，并尽量补充课程名称、资料类型和来源说明。
