# SILC 学习资源共享社区

**让知识积累，让后来者少走弯路。**

上海大学悉尼工商学院课程资料、学习笔记与复习经验的非官方共享社区。我们希望通过开放协作，让同学们的学习积累被更多人找到、使用和完善。

## 如何使用

1. **找到课程**：从上方分类或完整目录进入对应课程文件夹。
2. **选择资料**：查看文件夹说明，按资料类型和章节寻找所需内容。
3. **阅读或下载**：在 GitHub 查看支持预览的文件；需要离线使用时下载对应文件，或从仓库的 `Code → Download ZIP` 下载全部资料。

发现错误、链接失效或资料缺失？[提交 Issue](https://github.com/shu-silc-osc/course-materials/issues)，请附上课程名称和相关文件路径。

## 一起完善这份资料库

一份笔记、一次纠错、一段学习经验，都能帮助后来者少走弯路。

| 你想做什么 | 参与方式 |
| --- | --- |
| 补充笔记或复习资料 | 向 [course-materials](https://github.com/shu-silc-osc/course-materials) 提交 Pull Request，放入对应课程目录 |
| 修正内容或反馈问题 | [提交 Issue](https://github.com/shu-silc-osc/course-materials/issues) 或提交修正的 Pull Request |
| 改进社区介绍与导航 | 向 [.github](https://github.com/shu-silc-osc/.github) 提交 Pull Request |

分享资料时，请注明**课程名称、资料类型与来源**；有学期或版本信息时，也请一并说明。

请勿上传未授权教材、付费资料、教师个人信息、考试原题等可能涉及版权或隐私的内容。若不确定能否公开，请先通过 Issue 询问。
