# SILC 学习资源共享社区

非官方整理的上海大学悉尼工商学院学习资料汇总。

## 序言

这里是上海大学悉尼工商学院（SILC）学习资源的非官方整理与共享社区。我们希望通过开放、协作的方式，把课程资料、课堂笔记、复习提纲、作业参考与学习经验沉淀下来

本项目不代表学院官方立场，内容以学习交流为目的，欢迎纠错、补充与共建。

## 服务项目

- [Course Materials](https://github.com/shu-silc-osc/course-materials)：课程资料汇总。

后续将根据社区贡献，逐步扩展更多与课程学习相关的资料与服务。

## 贡献指南

欢迎共享与课程学习相关的资料、课堂笔记和整理内容。你可以通过提交 Pull Request 的方式补充资料、修正错误或改进目录结构。

提交内容前，请确认资料适合公开分享，并尽量补充课程名称、资料类型和来源说明。

请勿上传未授权教材、付费资料、教师个人信息、考试原题等可能涉及版权或隐私的内容。若不确定资料是否可以公开，请先通过 Issue 询问。
